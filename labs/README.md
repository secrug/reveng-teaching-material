# Labs

One file per session. Each lab has three tiers:

- **Core** — the floor. Everyone finishes it, and finishing it meets the
  session's learning outcome. If a student does only Core, the session worked.
- **Stretch** — the expected landing zone for most students in the time given.
- **Boss** — deliberately hard, so the fastest student never idles. Boss tasks
  carry the **explain-back** requirement: explain the mechanism to a neighbour
  with notes closed.

Every lab file gives the task, the deliverable, the solution outline (for the
lecturer/TA), and the common wrong turns to watch for while circulating.

**On solutions:** publish them *after* each session, and publish the *reasoning*,
not just the answer — the reasoning is the thing being taught. A solutions repo
that only lists flags teaches students that the flag was the point. It wasn't.

**On AI in labs:** students may use AI throughout. That is not a loophole — it's
the design. The Boss tiers and the Falsification Drill are AI-resistant by
construction (they demand evidence or explanation, not answers), and watching a
student try to shortcut a Boss tier with a model and fail is often the best
teaching moment in the block.
