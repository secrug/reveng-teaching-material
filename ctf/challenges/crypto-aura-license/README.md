# Counterfeit
**crypto · medium (300, dynamic) · keygen-me**

Every AURA-7 unit ships locked until it sees a valid licence. We have the
validator but not a single working licence — and the vendor is not returning our
calls. Make one. The validator prints the flag when it accepts.

```
./aura-license        # reads a 16-hex-character licence from stdin
```
Download: `aura-license`
