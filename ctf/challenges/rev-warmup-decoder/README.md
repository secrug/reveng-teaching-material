# Signal Primer
**rev · intro (100, dynamic)**

Warm up on the AURA-7 signal path. This verifier scrambles what you type and
checks it against a stored pattern. Feed it the right line and it accepts — that
line is the flag.

```
./warmup-decoder      # reads one line from stdin
```
