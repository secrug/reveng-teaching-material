# Hall of Mirrors
**rev · medium (300, dynamic)**

What you read is not what runs. This AURA-7 verifier keeps its key out of sight
until the moment it needs it; the tables in the binary look like noise. Make it
accept your input — that input is the flag.

```
./mirror              # reads one line from stdin
```
